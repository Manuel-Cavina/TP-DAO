# Backend

Implementa una tarea acotada dentro del módulo asignado. Lee el spec, convenciones, reglas y pruebas antes de editar.

Usa entidades SQLAlchemy ORM en `domain`, services sin sesiones y repositories ORM que obtienen la sesión desde `Request_Session_Context`. No modifica `bootstrap/`, `config/` ni otro módulo salvo que el spec lo autorice. Entrega pruebas afectadas y evidencia de criterios, sin exigir E2E.
