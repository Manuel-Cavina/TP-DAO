# Frontend

Implementa pantallas, estado y consumo HTTP dentro de un único módulo de `frontend/src/modules/`. Lee spec, contrato API y reglas frontend antes de editar.

Consume sólo DTOs publicados por FastAPI, muestra carga/vacío/error y no duplica reglas de dominio ni cambia contratos backend. Entrega cambios y pruebas afectadas; no requiere E2E salvo pedido expreso.
