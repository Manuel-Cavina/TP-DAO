# Navegación de Stocky

| Grupo | Destino principal | Vistas de trabajo |
| --- | --- | --- |
| Inicio | Panel operativo | Dashboard |
| Operaciones | Tablero operativo | Distribución, Recepción, Empaquetado |
| Inventario | Inventario por sede | Reposición, Recepción de proveedores |
| Catálogo | Productos | Categorías, Proveedores, Centros y locales |
| Ventas | Punto de venta | Caja y comprobantes, Devoluciones |
| Control | Trazabilidad | Reportes |

Las listas comparten: título y acción primaria, barra de filtros, resultado, tabla/lista y estados de carga, vacío y error. En móvil, los filtros pasan a un drawer y las filas conservan entidad, estado y próxima acción.
